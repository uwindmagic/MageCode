# ADR-002 · 统一展示投影与共享目录身份

日期：2026-10-25
状态：已接受并在 v0.3.0 实现
关联：REQ-010

## 背景

此前 Codex 列表和正文直接读 JSONL，助手 commentary 也可能进入界面。用户明确不需要完整历史镜像，只需要对话结果；同时要求一套所有工具共用的数据库，以及共享目录和原生组织两种导航。

## 决定

1. 使用单一 SQLite 展示投影；写入前排除分析、评论和工具过程。
2. Codex 最终答复只认 `phase=final`，不对缺失 phase 的助手旧记录做乐观猜测。
3. Tool/Connection、NativeProject/HubProject 分层；项目身份用规范化共享目录，不用标题。
4. 会话和消息以连接内原生 ID 幂等；用户注释与来源投影分表。
5. 启动读快照，手动触发同步；本版不引入调度。
6. 未验证格式的 Agent 只进入调查矩阵，不进入真实数据支持列表。

## 后果

优点：界面不会再展示过程分析；后续工具可复用同一仓储和导航；重同步不破坏用户数据。

代价：缺少 final 标记的旧助手答复不会显示；当前手动同步仍重新扫描 Codex 并重建各会话展示消息，不是增量索引。跨工具归并需等第二个连接器接入后才能做真实端到端展示验收。
