# MageCode v0.2.0 版本记录

日期：2026-10-25
需求：REQ-009
架构文档：v0.3.1

## 本版目标

续接 Codex 任务 `01a17456-ac5d-7592-a93e-e8430a661fea`，落实 AID002 的只读资料源建议，在 ChatGPT 栏目下接入本机 Codex 历史，并明确区分 Codex 与网页 ChatGPT。

## 已实现

- Rust 只读来源：从 `CODEX_HOME` 或默认用户目录 `.codex` 枚举 `sessions` 与 `archived_sessions`，仅纳入 `thread_source=user` 的记录。
- 会话摘要：保留原生 ID、项目目录、标题、更新时间、归档状态及 `codex://threads/<id>` 来源链接；重复 ID 选择最新文件。
- 按需正文：选中会话后读取用户与助手可见文本，过滤环境、权限和自动浏览器上下文；不读取开发者指令作为聊天消息。
- 三个 Tauri IPC 命令：会话列表、指定会话消息、原会话跳转。ID 经格式与来源存在性校验，不接收任意文件路径或 shell 文本。
- 前端整合：真实会话进入按项目/按工具视图，显示“Codex 本地 · 只读”；支持标题/项目搜索及已加载正文的当前前端搜索。
- 只读保护：真实正文不写入 localStorage，不提供发送、演示状态切换、任务勾选、用途编辑或归档修改。
- 设置页显示资料源目录、会话数量和重新读取入口；Token、实时状态与模型信息保持未知。
- 修复带冒号的 Codex 会话 ID 在 Hash URL 刷新、前进和后退时的解码问题。
- 保留 v0.1.1 的演示会话、主题、状态和本地编辑能力。

## 明确限制

- 浏览器预览只有演示数据；真实本地读取仅在桌面窗口可用。
- 尚未实现全量历史正文索引搜索、SQLite、文件监听和自动刷新；用户可在设置页手动重新读取。
- 尚未接入网页 ChatGPT 导出文件、全账号历史、实时运行状态、精确 Token 或双向续聊。
- 原会话按钮只请求系统打开 Codex 协议链接，最终跳转由本机客户端处理。
- 本版是来源验证阶段的过渡实现，正式 core/infrastructure 分层、分页 DTO 和结构化错误尚未完成。
